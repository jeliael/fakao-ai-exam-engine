# 工作流6：主观题/法律文书写作辅导

## 触发条件
- 用户要写案例分析（"帮我分析这个案例""这道主观题怎么答"）
- 用户要法律文书写作（"起诉状怎么写""辩护词格式"）
- 用户要主观题批改（"帮我改一下我的答案""这个回答能得多少分"）

## 执行步骤

### Step 1: 题目分析
- 识别主观题类型：案例分析/法律文书/论述
- 识别涉及科目与考点
- 提取题目中的法律关系与争议焦点

### Step 2: 答题框架
#### 案例分析题
```
### 答题框架（三段论式）

**结论**：明确回答问题（1-2句）

**法条依据**：
【依据】《XX法》第X条：法条原文

**案件涵摄**：
> 将法条构成要件与案件事实逐一对应
> "本案中，甲的行为……符合/不符合……的要件"

**结论重申**：因此，甲构成XX罪/承担XX责任
```

#### 法律文书题
```
### 文书格式
[根据文书类型提供标准格式模板]
- 起诉状：标题→当事人→诉讼请求→事实理由→落款
- 辩护词：标题→前言→辩护意见→结论→落款
- 判决书：标题→当事人→诉讼请求→查明事实→本院认为→判决主文→落款
```

#### 论述题
```
### 论述框架
1. 破题：明确论点
2. 论证：法理+法条+案例
3. 展开：正反两面分析
4. 总结：回扣论点
```

### Step 3: AI批改（如用户提交了答案）
- 运行 `python scripts\essay_grader.py --essay <用户答案> --rubric <评分标准>`
- 多维度评分：
  | 维度 | 分值 | 得分 | 评价 |
  |------|------|------|------|
  | 结论正确性 | 30% | | |
  | 法条引用 | 20% | | |
  | 逻辑分析 | 25% | | |
  | 语言表达 | 15% | | |
  | 格式规范 | 10% | | |
  | **总分** | 100% | | |

### Step 4: 逐段批注
```
### 逐段批注

**原文**：[用户答案第一段]
**批注**：
- ✅ 结论正确
- ⚠️ 缺少法条依据，应引用《XX法》第X条
- 💡 建议：在结论后立即给出法律依据

**原文**：[用户答案第二段]
**批注**：
- ✅ 逻辑清晰
- ⚠️ 涵摄不够完整，未将所有要件与事实对应
- 💡 建议：逐要件分析
```

### Step 5: 改进建议
```
### 改进建议

1. **法条引用**：每给出一个法律结论，必须紧跟法条依据
2. **涵摄完整**：将法条构成要件与案件事实逐一对应
3. **格式规范**：结论→依据→涵摄→结论的顺序
4. **语言精练**：避免冗余表述
```

### Step 6: 生成Word报告
- 运行 `python scripts\generate_essay_feedback_docx.py --feedback <批改JSON>`
- 输出：`output\主观题批改报告-YYYYMMDD.docx`

### Step 7: 可信度检查
- [ ] 答题框架符合法考标准
- [ ] 法条引用准确、现行有效
- [ ] 评分维度合理（结论/法条/逻辑/表达/格式）
- [ ] 批注具体可操作
- [ ] 无编造的法条或案例
