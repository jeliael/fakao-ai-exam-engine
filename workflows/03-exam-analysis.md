# 工作流3：真题解析

## 触发条件
- 用户提供题目要求解析（"帮我解析这道题""这道题选什么"）
- 用户问某年真题（"2022年刑法真题"）
- 用户问某考点的出题方式（"善意取得怎么考"）

## 执行步骤

### Step 1: 题目解析
- 识别题目类型：单选/多选/不定项/主观题
- 提取题目关键信息：案情、问题、选项
- 如题目不完整，主动询问补全

### Step 2: 考点定位
- 分析题目涉及的科目与知识点
- 对照 `knowledge\exam-points\key-points-map.md` 定位考点
- 标注考点频率（高频/中频/低频）

### Step 3: 法条依据检索
- 读取 `knowledge\laws\laws-index.json` 定位相关法条
- 新引用的法条 → 运行法条核验
- 确认法条现行有效

### Step 4: 逐项分析（客观题）
```
## 真题解析

**科目**：XX | **题型**：单选/多选/不定项 | **难度**：easy/medium/hard
**考点**：XX（高频/中频/低频）
**法条依据**：《XX法》第X条

### 题目
> [题目全文]

### 逐项分析
**选项A**：✅正确/❌错误
> 分析理由
【依据】《XX法》第X条：...

**选项B**：✅/❌
> 分析理由

**选项C**：✅/❌
> 分析理由

**选项D**：✅/❌
> 分析理由

### 正确答案：X

### 解题思路
1. 第一步：定性（识别法律关系）
2. 第二步：找法（定位法条依据）
3. 第三步：涵摄（案件事实→法条）
4. 第四步：结论

### 易错点
> 本题常见错误及原因

### 知识扩展
> 相关考点的延伸知识点
```

### Step 5: 主观题分析（如适用）
```
### 答题框架（三段论）
1. 结论：明确回答问题
2. 法条依据：引用具体法条
3. 案件涵摄：将法条适用于案件事实
4. 结论重申

### 评分要点
- 要点1（X分）：...
- 要点2（X分）：...
```

### Step 6: 可信度检查
- [ ] 答案有法条依据支撑
- [ ] 考点标注准确
- [ ] 逐项分析逻辑清晰
- [ ] 无凭感觉判断
- [ ] 标注真题来源（官方/机构回忆/模拟）
