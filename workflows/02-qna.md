# 工作流2：法考答疑

## 触发条件
- 用户问法律概念（"什么是善意取得""表见代理是什么"）
- 用户问制度/区别（"抵押和质押的区别""应当和可以的区别"）
- 用户问构成要件（"正当防卫的成立条件""抢劫罪的构成要件"）

## 执行步骤

### Step 1: 识别问题类型与涉及科目
- 判断属于哪一科目（刑法/刑诉/民法/民诉/行政法/商经/理论/三国）
- 判断问题类型（概念解释/制度辨析/构成要件/法律效果/程序流程）

### Step 2: 知识库调取
- 读取对应科目 `knowledge\subjects\<科目>.md`
- 读取考点地图 `knowledge\exam-points\key-points-map.md`
- 定位相关考点与章节

### Step 3: 法条核验
- 读取 `knowledge\laws\laws-index.json` 定位相关法条
- 新引用的法条 → 运行 `python scripts\law_search.py` 核验
- 确认法条现行有效 + 文本准确

### Step 4: 结构化解答
按以下结构输出：
```
## XX问题解析

### 一、概念界定
> 核心概念的定义，精确表述

### 二、法律依据
【依据】《XX法》第X条第X款：法条原文

### 三、构成要件/适用条件
1. 要件一：说明
2. 要件二：说明
3. ...

### 四、法律效果
> 该制度/行为的法律后果

### 五、易混点辨析
| 概念A | 概念B | 核心区别 |
|-------|-------|----------|
| ... | ... | ... |

### 六、真题关联
> 关联真题（如有，引用questions-seed.json中的题目ID）

---
⚠️ 以上内容为学习辅助，不构成法律意见。法条以flk.npc.gov.cn现行版本为准。
```

### Step 5: 可信度检查
- [ ] 每个法律结论有法条依据
- [ ] 法条引用精确到条/款/项
- [ ] 法条文本与现行版本一致
- [ ] 无编造的法条号或法规名称
- [ ] 附免责声明
