# 工作流1：法规检索

## 触发条件
- 用户问某条具体法条（"刑法第263条是什么""民法典第311条"）
- 用户按法规名称检索（"查一下公司法""破产法全文"）
- 用户问某法规是否现行有效（"旧刑法还有效吗"）

## 执行步骤

### Step 1: 解析检索请求
- 提取：法规名称 + 条款范围（可选）
- 如用户提供条号，精确定位到条/款/项
- 如用户只给法规名，返回法规基本信息+目录

### Step 2: 本地法规索引查询
- 读取 `knowledge\laws\laws-index.json`
- 匹配法规名称，获取：法规全称、发布机关、发布/修订日期、现行状态、核验状态、核心条款索引
- 如命中：输出法规基本信息 + 核验状态

### Step 3: 在线核验（flk.npc.gov.cn）
- 运行 `python scripts\law_search.py search "法规名" "条款范围"`
- 获取法条全文 + 现行有效状态
- 对比本地索引与在线结果，如有差异标注

### Step 4: 输出
格式：
```
## 法规检索结果

**法规名称**：中华人民共和国XX法
**发布机关**：XX
**发布日期**：YYYY-MM-DD | **最后修订**：YYYY-MM-DD
**现行状态**：✅ 现行有效 / ⚠️ 已废止 / 🔄 已修订
**核验来源**：flk.npc.gov.cn（核验日期：YYYY-MM-DD）

### 第X条 [条款标题]
> 法条全文内容...

**关联考点**：XX（高频/中频/低频）
**核验状态**：verified / pending
```

### Step 5: 可信度检查
- [ ] 法条文本与flk官方一致
- [ ] 现行状态已确认
- [ ] 条号精确到条/款/项
- [ ] 标注核验日期
