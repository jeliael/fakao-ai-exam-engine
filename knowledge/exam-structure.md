# 法考考试体系全览

## 一、考试概述
国家统一法律职业资格考试（法考），前身国家司法考试（司考），2018年改革为现行制度。由司法部组织实施。担任法官、检察官、律师、公证员等法律职业的法定准入考试。

## 二、考试结构（两阶段）

### 客观题考试
- 两卷（卷一、卷二）
- 每卷100题（50单选+50多选/不定项），每卷150分，总分300分
- 合格线：180分（全国线）
- 机考，每卷180分钟
- 单选每题1分，多选/不定项每题2分
- 少选/多选/错选均不得分

### 主观题考试
- 一卷，总分180分，合格线108分
- 机考（可申请纸笔），时长240分钟
- 以案例分析题为主
- 行政法与商经法二选一
- 不考三国法

### 成绩有效期
客观题合格成绩本年度和下一年度有效。

## 三、八大科目体系

### 卷一科目
1. 习近平法治思想
2. 法理学
3. 宪法
4. 中国法律史
5. 国际法
6. 司法制度和法律职业道德
7. 刑法
8. 刑事诉讼法
9. 行政法与行政诉讼法

### 卷二科目
1. 民法
2. 商法
3. 民事诉讼法（含仲裁制度）
4. 经济法
5. 知识产权法
6. 环境资源法
7. 劳动与社会保障法
8. 国际私法
9. 国际经济法

|------|------|------|----------|

## 四、主观题题型
| 题型 | 说明 | 参考分值 |
|------|------|----------|
| 案例分析题 | 结合案件事实进行法律分析 | 单题可达30分 |
| 法律文书题 | 撰写法律文书 | — |
| 论述题 | 就法律问题进行论述说理 | — |

## 五、报名条件

### 学历条件
1. 全日制法学类本科 + 学士学位
2. 非法学类本科 + 法律硕士/法学硕士及以上
3. 非法学类本科 + 从事法律工作满三年

### 放宽政策（2026—2030年）
放宽地区户籍可放宽至本科毕业，不限专业。须上传户口簿。

## 六、改革动态
- 2018年：司考→法考，分客观题+主观题两阶段，客观题成绩两年有效，全面机考
- 2026年：新一轮放宽政策（2026-2030年）
- 民法典实施后民法难度提升
- 刑诉法修订新增认罪认罚从宽等考点

## 七、备考策略

### 推荐复习顺序
刑法 → 民法 → 刑诉法 → 民诉法 → 行政法 → 商经法 → 理论法 → 三国法

### 各科策略
| 科目 | 策略 |
|------|------|
| 刑法 | 理解总则，记忆分则，不倍速听课 |
| 民法 | 打牢基础，关注民法典新修内容 |
| 刑诉法 | 建立框架，填充细节，区分"应当"与"可以" |
| 民诉法 | 放在程序中记忆，关注重点法条 |
| 行政法 | 隔段反复看，考点稳定 |
| 商经知 | 后期集中背诵，抓高频考点 |
| 理论法 | 主要多背，性价比极高 |
| 三国法 | 前期不大量投入，考前熟悉 |

## 八、通过率
综合通过率约13%；主观题通过率约50%。
