# 法考高频考点地图

> 按科目分级标注考点频率，指导备考优先级。基于历年真题分布与培训机构分析。

## 标注说明
- 🔴 高频：几乎每年必考，分值占比大
- 🟡 中频：隔年考查或分值中等
- 🟢 低频：偶尔考查，分值小
