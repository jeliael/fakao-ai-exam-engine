## 微服务拆分

| 服务 | 职责 | 技术栈 | 对应Skill工作流 |
|------|------|--------|----------------|
| Law Service | 法规检索/核验 | Python/FastAPI | 工作流1 |
| QnA Service | 法考智能答疑 | Python/LLM | 工作流2 |
| Exam Service | 真题解析/题库 | Python/FastAPI | 工作流3 |
| Mock Service | 模考组卷/评分 | Python/FastAPI | 工作流4 |
| Plan Service | 学习计划生成 | Python/LLM | 工作流5 |
| Essay Service | 主观题AI批改 | Python/LLM | 工作流6 |
| User Service | 用户/认证/权限 | Python/FastAPI | — |

## Skill → SaaS 演进路径

### Phase 1: Skill 原型（当前）
- 知识库体系 → 本地文件
- 工作流 → SKILL.md 定义
- 脚本 → Python单文件
- 输出 → Word文档

### Phase 2: API 化
- 知识库 → PostgreSQL + Elasticsearch
- 工作流 → FastAPI 端点
- 脚本 → 微服务
- 输出 → JSON API + Word下载

### Phase 3: SaaS 产品
- 多租户支持
- 用户系统/付费体系
- AI引擎集群（GLM/GPT）
- 前端Web/App/小程序
- 数据分析/学习推荐

## 扩展预留

| 方向 | 预留设计 |
|------|----------|
| 多考试类型 | 数据库 subject 字段支持法考/CPA/教资等 |
| 题库扩展 | questions 表 source 字段区分来源 |
| AI模型切换 | AI引擎层抽象接口，支持GLM/GPT/本地模型 |
| 多端支持 | API网关统一入口，适配各端 |
| B2B | 预留 tenant_id 字段，支持机构客户 |
